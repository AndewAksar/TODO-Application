# ADR-0003: Authentication Strategy — JWT (HS256)

## Status
Accepted

## Context

Требуется:
- Stateless аутентификация.
- Простота интеграции.
- Минимальная инфраструктурная сложность.

## Decision

Выбрана стратегия:

- JWT (JSON Web Token)
- Алгоритм: HS256
- sub = строковое представление users.id (int → str)
- Ограниченный срок действия токена
- Без хранения сессий на сервере

Секрет задаётся через environment variables.\
Ошибки аутентификации и инфраструктурные сбои
должны быть различимы на уровне observability.

## Alternatives Considered

1. Session-based auth — отклонено (stateful, требует хранения).
2. RS256 — отклонено (избыточно для текущего масштаба).
3. UUID в sub — отклонено (PK выбран int).

## Consequences

Плюсы:
- Stateless архитектура.
- Простота горизонтального масштабирования.
- Минимальная инфраструктурная зависимость.

Минусы:
- Невозможность мгновенного отзыва токена без blacklist.
- Зависимость от корректной конфигурации secret.
